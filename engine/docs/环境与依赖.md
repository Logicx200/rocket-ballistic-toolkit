# 环境与依赖

> **v2.0 变更**（详见 `CHANGELOG_v2.md`）：
> - 配置文件固定在 **`<root>/config.json`**（v1 有脚本误写 `common/config.json`）；
> - `run_all.ps1` 为 UTF-8 **带 BOM**，且执行策略受限时用
>   `powershell -NoProfile -ExecutionPolicy Bypass -File .\run_all.ps1 ...`；
> - `data/ne/*.geojson`（Natural Earth 中国范围底图）已随包提供；重建用 `python _tools/fetch_ne.py`（需 `pyshp`）；
> - `pandas` 为可选（`plot_sky.py` 自检会回退到 csv）。

## 1. 操作系统与 Python

- Windows 10/11（PowerShell 5.1+）；Google Earth Pro（可选，用于 KMZ 实测截图）。
- Python **3.12**（3.10+ 亦可）；依赖见 `requirements.txt`：`numpy scipy matplotlib pillow`。

安装方式二选一：

```powershell
python -m pip install -r requirements.txt
# 或复用已装好的 wheel 目录（本项目做法）：把 wheel 解到 _pylibs/，然后
$env:PYTHONPATH = "<工作区>\_pylibs"
```

## 2. 环境变量（每终端设置）

```powershell
$env:PYTHONIOENCODING = "utf-8"        # 中文输出
$env:MPLBACKEND       = "Agg"          # 无显示环境
$env:MPLCONFIGDIR     = "<工作区>\_tmp\mplconfig"   # 避免写用户目录
$env:PYTHONPATH       = "<工作区>\_pylibs"          # 若用 _pylibs
$env:RK_PYTHON        = "<python.exe 路径>"          # run_all.ps1 用
```

## 3. 中文字体

`common/plotstyle.py` 的 `setup()` 会注册 `C:\Windows\Fonts\msyh.ttc`（微软雅黑）。
若字体缺失，替换为 `simhei.ttf` 或 `simsun.ttc` 即可（改 `plotstyle.py` 顶部常量）。

## 4. 网络与数据源

| 用途 | 源 | 说明 |
|---|---|---|
| DEM | AWS SRTMGL1 `elevation-tiles-prod/skadi/N37/N37E112.hgt.gz` | `scripts/fetch_dem.py` 自动下载并解压到 `data/dem/`；1″ 瓦片约 25 MB/个 |
| 国界/省界/城市 | Natural Earth（1:10m/1:50m） | `common/boundaries.py` 自带精简数据或从 `fetch_*` 下载 |
| 航警 | 航警原文站点/官方 NOTAM | 需人工检索并记录 URL+访问日期 |

离线环境：提前在联网机器跑 `fetch_dem.py`，把 `data/dem/` 整目录拷过来即可。

## 5. 沙箱/受限环境注意

- `multiprocessing` 命名管道可能被禁（`PermissionError [WinError 5]`）→ **一律串行**（`mc.py` 已如此）。
- 只写工作区目录；`MPLCONFIGDIR` 指到工作区内。
- 大文件（DEM/原始网页存档）放 `data/`、`sources/raw/`，交付包默认不含。

## 6. Google Earth Pro 实测流程

1. 备份 `%LocalAppData%\Google\Google Earth\myplaces.kml`（记录 SHA256）；
2. 替换为只含 NetworkLink 的 myplaces 指向本项目的 **KML**（ASCII 别名副本，图标用 `file:///` 绝对路径）；
3. 启动 GE → 用 `PrintWindow` 截图（窗口 1550×830）→ 关闭；
4. **恢复 myplaces.kml 并校验 SHA256 一致**；
5. 截图保存到 `viz/`，记录到 `viz/GE实测验证.md`。

> 不要把 KMZ“另存到我的地点”：GE 会剥离 Document 级 Style，线条变白。
