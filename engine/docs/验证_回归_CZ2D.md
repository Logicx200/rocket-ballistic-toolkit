# 通用 N 级模型回归验证（vs 原 CZ-2D 专用模型）

## 1. 方法

- **参考**：本项目 `sim/` 下 CZ-2D 遥106 的专用 2 级模型（已交付、经 GE/航警/时序多重核对）。
- **被测**：`scripts/dynamics.py` 的通用 N 级实现（同一 config 描述、同一物理与积分设置）。
- **命令**：`python scripts/regression_check.py --reference <参考工程 sim 目录>`
- **配置**：`templates/config_cz2d.json`（参数取反演精确值，不用取整值）。

## 3. 差异来源与解释

1. **分离/SECO 的单步时序**：参考模型在“级分离”的那一步仍使用上一级已算好的推力；通用模型把推力段判定改为时间驱动（`main_on = t < end_met`），两者在 **0.02 s** 级存在一步差，累计约 0.4 m/s。
2. **参数取整**：配置中使用反演精确值后，轨迹差由 ~240 m 降至 ~125 m。
3. 其余物理子函数（USSA76 大气、J2 引力、WGS-84、ECI/ECEF、阻力、RK4）逐函数对比**逐位一致**。
4. 结论：通用模型可在 **km 级落点、0.1 km 级入轨半长轴**精度上复现原专用模型，满足 NOTAM 余量判定与可视化需求。
