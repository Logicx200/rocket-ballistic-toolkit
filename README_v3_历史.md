# 火箭弹道预报通用工具箱 v3.6 · 离线独立版

> **当前源码版本：v3.6（2026-11-26）**。在 v3.5 基础上新增：
> **自定义箭型发射时序**（助推器分离/各级分离/整流罩/SECO，留空=箭型库默认）。
> v3.5 的内容：
> **返回舱返回窗口/弹道**（空间站 OEM/TLE + 返回航警区 → 制动窗口 → 再入/开伞/着陆时序、
> 落地时刻、落点与 1σ 散布）；返回段可独立成任务（**不需要发射场/火箭/上升段**）。
> v3.4 的内容：
> **轨道发射窗口**（已知 RAAN / 太阳同步 LTAN / 空间站交会目标）、
> **CZ-2F 专用空间站交会**（官方 CMSE OEM/TLE → 交会窗口 → 入轨+对接时间线）、
> **离线高程自主导入**（GeoTIFF/HGT，弱网环境替代在线 DEM）。
> 详见 [`文档\07_新增功能_发射窗口与CZ2F_v3.4.md`](文档/07_新增功能_发射窗口与CZ2F_v3.4.md)。
> **注意**：`build\dist` 内的免安装版仍是 v3.2.3 冻结产物；按用户要求本版暂未重新打包，
> 需重新执行 `build\build.cmd` 才能带上 v3.6 功能（源码态已生效）。

把「一次火箭发射（航警 + 起飞时刻 + 箭型 + 观测点）」变成一整套成果：
**3-DOF 弹道 → 残骸落区/落点 → 入轨根数 → 轨道发射窗口 → 指定坐标天空轨迹 →
全国最大高度角地图 → 三维 Google Earth（KMZ）→ 不确定度 → 中文技术报告**；
CZ-2F 任务额外给出 **空间站轨道 → 交会窗口 → 入轨+对接时间线**。

**v3.0 与 v2.0 最大的区别：不再需要 AI 参与，也不再需要改代码/改 JSON 才能换任务。**

| | v2.0 | v3.0 离线版 |
|---|---|---|
| 谁来填配置 | AI/人逐字段查资料、改 `config.json` | 图形界面填 5 个框，或命令行给一份任务 JSON |
| 缺失数据（T0、箭型参数、观测点高程…） | AI 上网检索 + 人工判断 | **内置库 + 推理引擎自动补全**，逐字段标注来源与置信度 |
| 换任务要改代码？ | 3 个脚本写死案例常量，必须人工改 | 已全部参数化，零代码改动 |
| 运行方式 | `run_all.ps1`（需装 Python + 依赖） | 双击 exe（无需 Python、无需联网） |
| 报告 | 人工撰写 | 自动生成（含数据体检、结论、来源、自检结果） |
| 数值内核 | v2 accurate 口径 | 完全一致（回归逐位相同，见 `tests/run_regression.py`） |

**方式一：免安装版（推荐给最终用户）**

1. 解压 `火箭弹道工具箱_v3.2.3_便携版.zip` 到任意目录（不要放 `C:\Program Files`）；
2. 双击 `火箭弹道工具箱.exe`；
3. 在「①任务信息」选火箭型号、发射工位，T0 可留空（"未知，自动推断"）；
4. 「②航警」把 NOTAM 原文整段粘进去，点「解析」；
5. 「③观测点」粘坐标（`37°45′41″N 112°43′30″E 840m` 或 `37.761467,112.725219`）或选城市；
6. 长征二号F/神舟任务到「⑤空间站（CZ-2F）」确认空间站数据（内置 OEM 不覆盖任务日期时粘贴 TLE/导入 OEM）；如需返回舱，勾选「返回舱返回」并填着陆场/返回航警；
7. 点「⑥生成体检」看补全结果 →「开始计算」；
8. 完成后点「打开成果目录」，看 `report\弹道仿真报告.md`、`report\发射窗口计算.json`、`sim\返回舱返回.json` 与 `viz\*.kmz`。

## 缺失数据怎么被补上（v3 的核心）

| 缺什么 | 怎么补 | 置信度 | 说明 |
|---|---|---|---|
| **起飞时刻 T0** | 由航警 `B)` + 经验偏移（一级落区 B)≈T0−7~10 min）；首次仿真后再用「航警窗口必须覆盖到达时刻」做自洽校正 | 中 | 三个历史算例实测 T0 推断与真值**完全一致**（CZ-6A 差 0 s） |
| **发射方位角** | 发射场→一级/助推器落区质心的大圆初始方位；无落区时由目标倾角反算 | 中 | 反演会精化 |
| **箭型参数** | 内置 28 个型号库（长征全系+商业箭型），按型号名模糊匹配 | 高/中/低（逐条标注） | 未知型号可退化为"通用模板"，并明确警告只具备量级意义 |
| **发射工位** | 内置 28 个工位（含海上发射区），支持名称/别名/坐标匹配 | 高 | 用户直接给坐标时自动找最近的已知工位核对 |
| **参考轨道** | 用户给定 > 箭型典型轨道 > 由方位角反算倾角 | 中/低 | 若参考倾角与方位角估算差 ≥2°，自动启用末级平面机动（dogleg） |
| **观测点** | 城市名→内置 343 城市坐标+高程；任意坐标→SRTM 1″ / 内嵌 0.02° 粗 DEM | 高/低 | 高程缺失时依次用城市库→DEM→0 m |
| **地形瓦片** | 自动扫描本机历史工程的 `data/dem/gz` 导入（同盘硬链接）→ 可选在线下载 SRTM → 全无则内嵌粗 DEM 回退；也可**离线导入**自带 GeoTIFF/HGT | — | 粗 DEM 下首次出现时刻误差数十秒，报告会标注 |
| **空间站轨道（CZ-2F）** | 用户 OEM > 用户 TLE > 内置官方 CMSE OEM 快照（2026-11-20~27）> 内置 TLE > 在线拉取 | 高/中 | OEM 精密星历优先；TLE 数天后沿迹误差可达数度 |
| **交会窗口/入轨+对接** | 相位调整 + Hohmann + 末段 Lambert，ΔV/时长预算自动判定 | 中 | 工程估算模型，不是飞行程序 |
| **航警原文** | 支持 ICAO 原文/中文任务卡/只有 Q 行圆/只有多边形顶点等多种粘贴格式 | — | 无航警时进入「预测落区」模式（明确标注非官方） |
| **制导参数** | 内置库初值 + **自动生成反演边界**（按箭型置信度与工作段时长）+ 自动反演 | — | 反演约 40 s（本机实测），目标值会被回填 config |
| **数值口径/权重/窗口裕度** | 按任务自动选择 | — | 换口径无需人工改 |

所有补全结果都写进 `config.json` 的 `mission._provenance`，并在界面「数据体检」页与报告 §1.1
逐行展示：**字段 / 取值 / 来源（用户/内置库/自动推断/默认值）/ 置信度 / 说明**。

## 关键约定（务必遵守）

1. **不编造**：所有数值可追溯到脚本输出或内置库的公开来源（`app/data/*.json` 每条带 sources/confidence）。
2. **数据体检要看**：来源=自动推断/默认值、置信度=低的字段，结论必须打折扣（报告会自动标注）。
3. **航警多边形顺序是 `[lat, lon]`**（不是 GeoJSON 的 lon/lat），这是最常见错误。
4. **T0 按 UTC 存储**，界面输入默认按北京时间解释（可切 UTC），报告同时给 UTC 与北京时。
5. 结果仅用于公开信息分析与教学，**不能**作为飞行安全或工程依据。

## 已知限制

- 3-DOF 模型：不含侧向机动细节、风场、发动机调节、分离扰动；残骸按无控弹道+阻力估算。
- 轨道平面窗口假设不同 T0 时弹道相对地球固连、整条轨迹随地球自转旋转；不是六自由度制导。
- CZ-2F 交会为共面圆轨道 + 相位调整 + Hohmann + 末段 Lambert 的工程估算模型，
  **不是飞行程序**；TLE 回退在历元数天后沿迹误差可达数度。
- 内置空间站 OEM 只覆盖 2026-11-20 ~ 2026-11-27；其他日期需导入新 OEM/TLE 或在线拉取。
- 离线高程遮挡要求自定义源完整覆盖观测点半径外接矩形；部分覆盖时点采样仍用自定义源。
- 内置库中约 20 个型号的分级质量/推进剂为**按起飞质量比例的工程估值**（条目内已标注），
  未反演时可能偏离真实弹道；正式使用建议开启反演并核对落区。
- 粗 DEM（内嵌 0.02°）只能给出地形遮挡的近似值；正式天空可见性结论请补 SRTM 或导入高程。
- 航警需用户提供原文，程序**不联网检索 NOTAM**。
- 中国以外任务：全国地图底图（国界/省界）仍是中国范围，网格会外扩但底图不覆盖。
- **本版暂未重新打包 exe**（用户要求），`build\dist` 仍是旧版。
