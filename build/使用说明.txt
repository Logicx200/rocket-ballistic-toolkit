火箭弹道工具箱 v4.3.0 · Windows 免安装版（打包 exe）
================================================================

一、怎么启动
----------------------------------------------------------------
1. 双击本文件夹里的 「火箭弹道工具箱.exe」。
2. 会同时出现两个窗口：黑色的命令行窗口（进度与日志）和图形界面窗口。
   计算过程中命令行窗口会滚动输出每一步的进度，属正常现象。
3. 不需要安装 Python，也不需要联网；整个文件夹拷到任意 Windows 10/11 x64
   机器都能直接运行（例如 U 盘、桌面、D 盘）。

提示：
* 第一次启动会慢 3~10 秒（matplotlib 建立中文字体缓存），之后正常。
* 程序需要在本文件夹内写 settings.json / 作品\ / user_data\；
  如果放在 C:\Program Files 这类只读目录，程序会自动改用
  %LOCALAPPDATA%\RocketKit 存放可写数据（程序照常可用）。
* 若杀毒软件/企业策略拦截未签名 exe，请把本文件夹加入信任或白名单。

二、第一次用的最短路径
----------------------------------------------------------------
1. 左上角点「载入示例」；
2. 点「① 生成体检」，看哪些字段是推断的；
3. 点「② 开始计算（F5）」；
4. 完成后到「⑧ 运行与成果」看 report\任务摘要.md 与 report\成果清单.md。

成果默认输出到本文件夹下的 作品\<日期_型号_工位>\（菜单可改工作区根目录）。

三、命令行用法（同一套功能，便于批处理与自检）
----------------------------------------------------------------
在本文件夹地址栏输入 cmd 打开命令行，然后：

  火箭弹道工具箱.exe --env
      环境自检（引擎目录、内置库条数、粗 DEM、依赖版本）

  火箭弹道工具箱.exe --cli --demo cz2d --workdir "作品\示例"
      跑内置示例（常规发射，验证整条链路）

  火箭弹道工具箱.exe --cli --mission 任务.json --workdir "作品\我的任务"
      跑界面「保存任务」导出的任务 JSON

  火箭弹道工具箱.exe --cli --mission 任务.json --modules export,report,qc
      只跑指定模块（逗号分隔）

  火箭弹道工具箱.exe --import-dem "D:\高程\山西.tif"
      导入离线高程（GeoTIFF / HGT / ZIP）后退出

  火箭弹道工具箱.exe --help
      全部参数

四、数据与目录
----------------------------------------------------------------
本程序把「只读资源」和「可写数据」分开：

* 只读资源（随 exe 打包）：_internal\app\data（内置箭型/工位/城市/轨道/
  空间站 OEM/粗 DEM）、_internal\engine（数值内核与出图脚本、Natural Earth
  底图、KML 图标）、_internal\文档（v4 用户文档，界面「帮助 → 打开文档目录」）。
* 可写数据（运行期生成，在本文件夹旁）：settings.json、作品\、user_data\
  （我的箭型 / 我的轨道 / 时序模板）。
* SRTM 高程瓦片缓存：%LOCALAPPDATA%\RocketKit\dem（体积大，默认不随包，
  程序在需要时自行下载或由 --import-dem 导入）。
* 内置空间站 OEM 只覆盖 2026-11-20 ~ 2026-11-27；其他日期请导入新 OEM/TLE。

五、两处与源码版的差异
----------------------------------------------------------------
1. 打包版不允许并行多进程（PyInstaller 冻结态下 multiprocessing 不可靠），
   蒙特卡洛与反演会自动串行；速度与源码态单进程一致。
2. 本版为控制台 + 图形双模式：命令行模式（--cli / --env）与界面模式是
   同一个 exe，控制台窗口请保持打开，关闭它会结束程序。
