# 内置库全库体检报告（v3.3）—— 28 个箭型 / 28 个工位

> 起因：2026-11-23 的 CZ-6C 算例暴露"库里数据本身有问题"（二级装药少 3 t、抛罩时刻早 36 s），
> 于是把**整库 28 个箭型**按同一套判据重筛一遍，避免"只修了一个型号"。
> 本报告只解决"箭型物理参数是否自洽"；航警/轨道/观测点等任务侧数据已由 `test_db_validate.py`（8894 项）覆盖。
> 仅供公开信息分析与教学使用。

## 1. 判据（三查）

| 检查 | 判据 | 说明 |
|---|---|---|
| **A 质量账目** | 分级干重+装药+整流罩+适配器+载荷 与 `liftoff_mass_kg` 闭合 ≤2% | 与官方公开起飞质量对比（原 CZ-6C 靠砍二级装药才闭合） |
| **B 起飞推重比** | 0.9 ≤ T/W ≤ 3.0 | 海平面推力 / 起飞重力 |
| **C 运力闭合（核心）** | 可用理想 Δv = Σ Isp·g·ln(m₀/m_f)（逐级，含联合助推）；需求 Δv = v_circ(典型轨道) − 自转投射 + 经验损失（液体 1.75 / 固体助推 1.9 / 全固体 2.2 km/s）。余量 < **−0.45 km/s → 不自洽**；< +0.15 → 偏紧 | CZ-6C 原条目（25 t 装药）在此检查下余量 **−1.0 km/s**，是本次事故的直接判据 |

实现为可重复运行的体检脚本：[`tests/test_perf_consistency.py`](../tests/test_perf_consistency.py)（明细 `tests/perf_consistency_report.json`）。

## 3. 各条结论与处理

### 3.1 真问题：3 条"运力不闭合"

| 型号 | 缺口 | 原因判断 | 处理 |
|---|---|---|---|
| 朱雀二号 zq2 | −1.18 km/s | 一级 4×天鹊-12 的比冲取了 320 s（公开 vac 约 337 s）、二级干重 6 t 偏大、且"改进型"6 t 运力与"初始型"219 t 质量混用 | 降为低置信度 + 注记；**未改数值**（缺口太大，任何单点调整都会变成"新估值掩盖旧估值"） |
| 谷神星一号 gsx1 | −0.86 km/s | 四级固体比冲取 250/255/280 s 偏保守（复合固体 vac 常见 270–290 s），干重估计偏重 | 同上 |
| 快舟十一号 kz11 | −0.51 km/s | 同上（分级数据全为比例拆分） | 同上 |

> 未做"按运力反标定干重"的原因：试算表明要把这 3 条拉回到 +0.35 km/s，干重需压到总质量的 3–7%（固体推进剂占比 >95%），
> 这比现状更不符合物理。正确做法是补齐权威分级数据（比冲/装药/干重），属下一步工作。

### 3.2 锚点与 GTO 口径（不改数值）

* **锚点**（cz2d / cz2f / cz6a）：`vehicle` 参数直接来自已与真实任务对齐的历史 config，本次**未动任何数值**。
  cz2f 显示 −0.77 km/s 属"公开数据自身的矛盾"（464 t 起飞质量 + 8.4 t LEO + 公开分级质量三者不能同时严格成立），
  但该条目来自实测标定，可信度高于理论闭合，故只标注不修改。
* **GTO 构型**（cz3b/cz3c/cz5/cz7a）：GTO 的"需求 Δv"对末级关机策略（一次/两次点火、滑行）极敏感，
  本体检用统一经验值 12.0 km/s 只作量级对比，不进入硬判定。

### 3.3 其它发现

* **cz6（长征六号）**：真实构型是**三级**（一级 YF-100 + 二级 YF-115 + 三级 4×YF-85 上面级），
  本库只建了两级 —— 对 SSO 任务的运力与末段弹道会明显偏离。已降为低置信度并加注记，待补上述级参数。
* **cz8a（长征八号甲）**：质量账目 379.0 t vs 公开约 371 t（+2.2%）；二级用 YF-75H 简化成 2×84 kN，
  运力档（700 km SSO 7 t）未核实。已加注记。
* 其余 20 条：三查全部通过（其中 cz6c 为本次重建后 **+1.19 km/s**，是库里运力闭合最健康的条目之一）。

## 5. 建议的下一步（按性价比排序）

1. **补 cz6 三级上面级参数**（一级 YF-100/二级 YF-115/三级 4×YF-85），影响所有长六任务；
2. **按公开运力重算 kz11 / gsx1 / zq2 的分级装药与比冲**（缺口 −0.5~−1.2 km/s，现仅有量级精度）；
3. `zq2/cz8a/cz12` 等"改进型运力与初始型质量混用"的条目，建议拆成两个 id（如 `zq2` / `zq2a`）；

   （CZ-6C 已按此路线处理）。
