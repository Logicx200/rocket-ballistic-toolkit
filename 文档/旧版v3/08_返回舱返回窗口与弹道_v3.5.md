# 返回舱返回窗口与弹道（v3.5）

> 本文说明 **「空间站轨道 + 返回航警 → 返回舱制动窗口、再入弹道、落地时间与大致落点范围」**
> 功能的输入、模型、算法、输出与限制。
> 结论仅供公开信息分析与教学使用，**不是实际返回/回收程序，不能作为飞行安全依据**。

## 1. 功能定位

CZ-2F/神舟任务的返回段与发射段是两套独立问题：

- 发射段：地面 → 入轨 → 交会对接（v3.4 已实现）；
- 返回段：空间站轨道 → 制动离轨 → 再入 → 开伞 → 着陆（v3.5 新增）。

本功能复用 v3.4 的空间站轨道数据（官方 CMSE OEM 优先，其次 TLE/在线），
结合**返回航警区**（着陆区多边形 + B)/C) 有效时段）计算：

1. 哪些制动时刻能让返回舱落进着陆区，且落地时刻在航警 B)/C) 内；
2. 选中机会的完整「制动 → 再入 → 开伞 → 着陆」时序；
3. 落地时刻、落点经纬度、飞行时间、峰值动压/过载/热流；
4. 由参数小扰动估计的 1σ 落点椭圆（"大致范围"）。

## 2. 输入

### 2.1 空间站轨道

沿用 `config.station`：

- `source=auto`：用户 OEM > 用户 TLE > 内置官方 CMSE OEM 快照 > 内置 TLE > 在线；
- 内置 OEM 覆盖 `2026-11-20T00:00Z ~ 2026-11-27T00:00Z`；
- 其它日期请导入新的 OEM/TLE（GUI ⑤ 空间站页）。

### 2.2 返回航警区

优先使用 `config.notams` 中满足以下任一条件的区：

- `stage_hint` / `object_hint` / `raw_text` / `q_line` 含
  「返回 / 返回舱 / 回收 / 着陆 / 落区 / landing / return / capsule / recovery」；
- 或在 GUI 勾选「把当前航警区作为着陆区」（`return_capsule.use_current_notams=true`）。

每个区需要：

- `polygon_latlon`：≥3 个 `[lat, lon]` 顶点；
- `b_utc` / `c_utc`：返回航警有效时段（落地时刻必须落在该区间）。

没有可用航警区时，按固定着陆场 + 半径判定（默认四子王旗 42.27N/111.70E，R=50 km）。

### 2.3 返回舱参数

`config.return_capsule`：

| 字段 | 默认 | 说明 |
|---|---|---|
| `enabled` | false | 是否计算返回段 |
| `landing_site` | 四子王旗 42.27N/111.70E/R=50 km | 固定着陆场 |
| `use_current_notams` | false | 是否把当前航警区当着陆区 |
| `search_start_utc` / `search_end_utc` | 空 | 制动时刻搜索范围；空=航警 B−3 h ~ C+1 h 或 T0±6 h |
| `deorbit_dv_mps` | 120 | 标称反向制动 ΔV |
| `ld_ratio` | 0.30 | 升阻比（常值） |
| `bank_deg` | null | 倾侧角；null=按候选时刻自动扫描 |
| `auto_dv` / `auto_bank` | true | 是否在候选点自动选 ΔV/倾侧角 |
| `mass_kg` / `cd_area_m2` | 3000 / 5.0 | 返回舱质量与 Cd·A |
| `drogue_cd_area_m2` / `chute_cd_area_m2` | 20 / 1200 | 减速伞/主伞 Cd·A |
| `drogue_deploy_km` / `main_deploy_km` | 10 / 6 | 开伞高度 |
| `entry_interface_km` | 120 | 再入界面 |
| `coarse_step_s` / `scan_step_s` | 300 / 10 | 粗扫/细扫步长 |

## 3. 模型

`engine/common/reentry.py` 实现 3-DOF 简化返回舱：

- 球形地球 + J2 重力；
- US Standard Atmosphere 密度（与上升段 `dynamics.py` 同口径）；
- 大气随地球共转，阻力按相对速度 `v − ω×r`；
- 升力 = (L/D) × 阻力，方向由常值倾侧角在「当地垂直—速度平面」内旋转；
- 再入界面 120 km；减速伞 10 km；主伞 6 km；主伞面积在 5 s 内线性充气；
- 伞降段用半隐式积分，避免大阻力 + 固定步长 RK4 的刚性震荡；
- 落地判据 h≤0，末步线性插值落点/时刻。

峰值动压、过载（阻力加速度/9.80665）、Sutton-Graves 热流只作量级参考。

### 3.1 返回阶段与分离点

返回胶囊没有“火箭级”，但有明确的**任务阶段**和**分离点**。模型按以下工程阶段输出
（时刻均为可配置阶段标记，不是精确分离动力学）：

| 阶段 | 默认起点/终点 | 说明 |
|---|---|---|
| 停泊/分离准备 | 船站分离 → 轨道舱分离 | 与空间站分离后准备返回 |
| 独立飞行/制动准备 | 轨道舱分离 → 制动开始 | 轨道舱分离 |
| 制动 | 制动开始 → 制动结束（默认 150 s） | 反向制动 ΔV；模型按瞬时制动，结束点仅作阶段标记 |
| 自由滑行 | 制动结束 → 再入界面 | 推进舱分离（默认制动后 300 s） |
| 再入 | 再入界面 → 减速伞 | 气动减速 |
| 伞降 | 减速伞 → 着陆 | 减速伞/主伞 |
| 着陆 | 着陆时刻 | — |

默认分离时序（可在 `config.return_capsule` 改）：

- `undock_lead_s=3600`：船站分离 = 制动前 1 h；
- `orbital_sep_lead_s=600`：轨道舱分离 = 制动前 10 min；
- `prop_sep_delay_s=300`：推进舱分离 = 制动后 5 min；
- `burn_duration_s=150`：制动阶段标记时长。

分离点坐标：

- 船站分离/轨道舱分离：按**空间站轨道**在对应时刻的星下点/高度给出（近似）；
- 推进舱分离：按返回舱**滑行段时序**插值；
- 三者都输出经纬度、高度、速度，并写入 KML 和报告。

### 3.2 返回前 30 min 的空间站/神舟轨道

返回段不只从制动时刻开始：v3.5 额外计算**制动前 30 min** 的空间站轨道，以及
**神舟飞船分离后的轨道**（从船站分离状态按二体+J2 递推，窗口内 10 s 采样）。

- CSV：`sim/返回前30分钟_空间站与神舟.csv`（object/t_utc/lat/lon/alt）；
- KML：`viz/返回舱弹道.kml` 里的两条 LineString
  「空间站（返回前30min）」「神舟飞船（返回前30min，分离后）」；
- 报告 §3.4。

CZ-2F 发射/交会任务也把上下文扩到**任务前后各 30 min**：
`station_track` 本身已覆盖 T0−6h~T0+30h，`rendezvous` 另写
`sim/CZ2F_任务前后30min_空间站.csv`（T0−30min ~ 对接+30min，1034 点 @30 s），
并叠加到 `viz/弹道三维_含残骸坠落.kmz` 的「任务前后 30 min 上下文」Folder。

## 4. 算法
1. **标称飞行时间**：搜索区间中点做一次完整仿真，得到 `T_nom`（约 3800–4100 s）；
2. **粗扫**：按 `coarse_step_s`（默认 300 s）扫描制动时刻；每个时刻扫描
   倾侧角 `[-70, -40, 0, 40, 70]°`（`auto_bank=true`），取落点距着陆区最近的一组；
3. **局部加密**：对粗扫的 1–4 个距离极小点，做 ΔV 小网格 + 倾侧角小网格，
   再用三分法细化制动时刻；
4. **细扫**：在最近点 ±(粗扫步长+180 s) 内按 `scan_step_s`（默认 10 s）仿真，
   标记「落点在区内/半径内 + 落地时刻在航警 B)/C) 内」的可行点；
5. **窗口边界**：向两侧逐 2 s 探到不可行，再二分到 1 s；
6. **选中机会**：可行窗口内距标称 T0 最近的一次；无可行窗口时给出距着陆区最近的一次；
7. **落点散布**：对选中机会扰动 ΔV ±0.5 m/s、倾侧角 ±0.5°、质量 ±1%，
   用 9 个落点样本估计 1σ 协方差椭圆。

> 性能：粗扫每个时刻要跑完整 3-DOF，约 0.6–1 s/次。1–2 h 航警窗口通常 2–5 min；
> 24 h 全扫会明显更久，建议用航警 B)/C) 或 `search_start/end` 收窄。

## 6. 在 GUI 中使用

### 6.1 独立返回任务（推荐：没有发射场）

返回舱返回本来就没有「发射场」：它是空间站轨道 → 制动 → 再入 → 着陆。
v3.5 支持**仅返回任务**，不需要选火箭、发射工位、起飞 T0，也不需要跑上升段：

1. 「⑤ 空间站」页 → 勾选「返回舱返回」→ 勾选「仅返回任务：不需要发射场/火箭/上升段」；
2. 任务页的发射场/火箭可留空（T0 可填返回标称时刻，留空则用返回航警 B)/C) 中点）；
3. 填着陆场或勾选返回航警区；
4. 「开始计算」→ 只执行 环境 → 空间站 → 返回舱 → 报告 → 自检；
5. 报告是独立的「返回舱返回任务技术报告」，不含发射场/上升段/残骸落区。

CLI 等价输入（MissionInput JSON）：

```json
{
  "name": "2026-11-26 返回舱返回",
  "return_only": true,
  "return_enabled": true,
  "t0_text": "2026-11-26 21:20",
  "station_enabled": true,
  "return_landing_lat": 42.27,
  "return_landing_lon": 111.70,
  "return_landing_radius_km": 50
}
```

生成的 `config.json` 只有 `mission / notams / station / return_capsule / _v3`，
**没有 `launch_site`、`vehicle`、`guidance`、`grid`**，模块表里 `export=false`。

### 6.2 在 CZ-2F 发射任务里附带返回段

如果同一次任务既要算发射/交会、又要算返回：

1. ⑤ 空间站页 → 确认空间站轨道数据可用（可点「校验/识别数据」）；
2. 在「返回舱返回」框勾选启用（不要勾「仅返回任务」）；
3. 填着陆场或勾选「强制把当前全部航警区作为着陆区」；
4. 搜索时段留空即按返回航警 B)/C) 或 T0±6 h；
5. ΔV/L/D/倾侧角留默认；倾侧角留空=自动；
6. 主界面「开始计算」→ 流水线在「交会对接」之后执行「返回舱返回窗口与弹道」；
7. 结果看 `sim/返回舱返回.json`、`sim/返回舱_时序.csv`、`sim/返回舱弹道.png`、
   `viz/返回舱弹道.kmz`，报告 §5.6。

## 7. 工程示例（不是官方任务）

用内置 CMSE OEM、四子王旗 42.27N/111.70E/R=50 km、L/D=0.3、自动 ΔV/倾侧角：

| 项目 | 结果 |
|---|---|
| 制动窗口 | 2026-11-26 20:07:36 ~ 20:07:49 UTC（13 s） |
| 选中制动 | 20:07:43 UTC |
| 落地 | 21:18:23 UTC（北京时 11-27 05:18:23） |
| 落点 | 42.07N, 111.81E（距场中心约 23.7 km） |
| 飞行时间 | 4239 s（70.7 min） |
| 制动 ΔV / 倾侧角 | 100 m/s / −70° |
| 峰值动压/过载/热流 | 28.0 kPa / 4.8 g / 103 W·cm⁻² |
| 1σ 落点椭圆 | 65.0 km × 0.60 km |

> 该例只用于验证算法链路；真实神舟返回的制动 ΔV、倾侧角剖面、开伞高度、
> 气动参数与落点散布均需按任务实际数据替换。

## 8. 局限

- 常值 L/D + 常值倾侧角，不是真实升力控制/落点制导；落点误差几十 km；
- 未计风、开伞过程载荷、气动参数随马赫/攻角变化、烧蚀、地球扁率高阶项；
- SRTM/着陆区地形不参与返回段（落点按椭球面）；
- 航警区多边形按球面点内判定，边界精度约数十米；
- 落点散布是参数扰动协方差，不是官方残骸区；
- 不能用于实际返回/回收决策。
