# 自定义不同箭型发射时序（v3.6）

> 目的：允许按任务手动指定**助推器分离、各级关机/分离、整流罩分离、末级 SECO**
> 的时刻；**不勾选/留空时使用箭型库默认数据**。

## 1. 默认数据从哪来

每个箭型在 `app/data/rockets.json` 里已有：

- `vehicle.boosters.jettison_met`：助推器程序分离时刻（可空）；
- `vehicle.stages[i].phases[].end_met`：发动机程序关机/阶段切换；
- `vehicle.stages[i].seco_met`：末级程序关机（SECO，可空）；
- `vehicle.fairing.sep_met` / `guidance_defaults.t_fairing`：整流罩分离；
- 没有显式时刻的级分离：按**推进剂耗尽**自然分离。

默认情况下不写任何覆盖，仿真完全沿用上述数据。

## 2. GUI 操作

「④ 运行选项」页底部新增 **「发射时序（按箭型默认；可自定义分离/抛罩/SECO）」**：

> ④/⑤ 页内容较长，已加**纵横滚动条 + 鼠标滚轮**；窗口再小也能滚到「发射时序」，
> 不会截断。运行日志/表格等内部滚动控件仍保持自己的滚轮。

1. 先在「① 任务信息」选火箭型号；
2. 进入 ④ 页，表格会自动按该箭型生成：
   - 助推器分离（有助推器时）
   - 第 1 级关机/分离
   - 第 2 级关机/分离 …（按级数）
   - 整流罩分离
   - 末级关机（SECO）
3. 勾选「自定义当前箭型的发射时序」，修改需要覆盖的时刻（秒，MET）；
4. 留空项 = 该箭型默认；
5. 「恢复默认时序」清空所有覆盖。

## 3. 配置结构

`config.json`：

```json
"launch_sequence": {
  "custom": true,
  "source": "user",
  "defaults": {
    "boosters_sep_s": null,
    "stage_sep_s": [null, null],
    "fairing_sep_s": 200.0,
    "seco_s": null
  },
  "values": {
    "boosters_sep_s": null,
    "stage_sep_s": [135.0, null],
    "fairing_sep_s": 215.0,
    "seco_s": 340.0
  },
  "warnings": []
}
```

应用方式：

- `values.boosters_sep_s` → `vehicle.boosters.jettison_met`
- `values.stage_sep_s[i]` → `vehicle.stages[i].sep_met`（非末级）
- `values.fairing_sep_s` → `vehicle.fairing.sep_met` + `guidance.t_fairing`
- `values.seco_s` → 末级 `vehicle.stages[-1].seco_met`

`custom=false` 时 `values` 只作展示，仿真仍用箭型库默认。

## 4. 语义与限制

- **提前分离**：在指定时刻抛离该级；该级剩余推进剂随级抛掉（质量计算已扣除）；
- **晚于自然耗尽**：该级已无推进剂，仍按自然耗尽时刻分离（不会悬空等待）；
- **整流罩/SECO**：可提前或推迟，按指定时刻执行；
- 自定义时序会改变入轨能量：提前 SECO 可能得到负近地点/大椭圆，QC 会判“入轨根数异常”，
  这是物理结果而非程序错误；
- 反演/优化只改制导参数，不会改发射时序覆盖值。

## 5. 报告与数据

- 报告 §2.0「发射时序」表：每个时序项采用值 + 来源（用户自定义/箭型库默认）；
- `config.json` 的 `launch_sequence` 完整记录默认值、采用值、警告；
- 事件表 `sim/弹道事件表.csv` 反映实际分离/关机时刻。

## 6. 示例（CZ-2C）

```json
"launch_sequence": {
  "custom": true,
  "stage_sep_s": [135],
  "fairing_sep_s": 215,
  "seco_s": 340
}
```

事件表：

| 事件 | T+ (s) |
|---|---|
| 一级关机/一二级分离 | 135.000 |
| 整流罩分离 | 215.000 |
| 二级主机关机 | 330.000 |
| 二级关机(SECO) | 340.000 |

> 该示例把 SECO 提前到 340 s，入轨能量不足（近地点为负），QC 会失败——这是预期结果，
> 说明自定义时序确实生效。正常任务应填与推进剂/目标轨道匹配的时刻。
