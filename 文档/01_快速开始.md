> 适用版本：v4.0（2026-11）

# 01 快速开始

目标：**10 分钟内**从一台只有 Python 的 Windows 机器，走到看见本任务的一整套成果。

## 0. 路线图

| 用时 | 做什么 | 看到的反馈 |
|---|---|---|
| 2 min | 装依赖（一次性，需联网） | `pip` 输出 Successfully installed … |
| 10 s | `python -m app.main` 打开界面 | 标题栏 `火箭弹道工具箱 v4.0 · 离线版` |
| 30 s | 工具条「载入示例」 | 顶部概要条出现「太原 LC-9」「长征二号丁」 |
| 20 s | 工具条「① 生成体检」 | 跳到第 7 步，列出每个字段的取值/来源/置信度 |
| 1~3 min | 「② 开始计算（F5）」 | 第 8 步进度条、步骤台账逐行变绿 |
| 2 min | 读 `report\任务摘要.md`、`report\成果清单.md` | 一页纸结论 + 全量文件与步骤状态 |

## 1. 环境要求

| 项 | 要求 | 说明 |
|---|---|---|
| 操作系统 | Windows 10/11（64 位） | 界面用 tkinter；`启动器.bat` 用 cmd |
| Python | **3.10 及以上** | `启动器.bat` 会依次找 `py -3`、`python`、常见安装路径 |
| 依赖库 | 见下表 | `requirements.txt` 已列全 |
| 网络 | **运行期不需要** | 只有安装依赖、以及手动勾选「允许联网补全」时才联网 |
| 磁盘 | 首次约 1 GB 以内 | 含 SRTM 瓦片缓存（每片约 25 MB 解压后） |

`requirements.txt` 的实际内容：

| 包 | 版本约束 | 用途 |
|---|---|---|
| numpy | >=1.26,<3 | 数值内核（RK4 积分、差分进化、轨道根数） |
| scipy | >=1.11,<2 | 差分进化、插值、求根 |
| matplotlib | >=3.7,<4 | 所有出图（天空轨迹、全国地图、地形判读） |
| pillow | >=10,<13 | PNG 尺寸检查、KMZ 图标处理 |
| pandas | >=2.0,<3 | `engine/scripts/plot_sky.py` 读 CSV |
| python-docx | >=1.1,<2 | 技术报告额外导出 `.docx`（不装只出 `.md`） |
| sgp4 | >=2.20,<3 | TLE 传播（空间站轨道、参考轨道 TLE 导入） |

## 2. 安装

```powershell
cd "F:\DeepSeek工作区\火箭弹道工具箱_V4.0"

# 建议用虚拟环境（可选）
py -3 -m venv .venv
.\.venv\Scripts\Activate.ps1

python -m pip install -U pip
python -m pip install -r requirements.txt
```

验证依赖与目录是否就绪（不打开界面）：

```powershell
python -m app.main --env
```

输出里重点看这几行：`引擎存在: True`、`numpy/scipy/matplotlib/PIL/sgp4` 有版本号、
`内置库` 里 `rockets: 28`、`launch_sites` 的数量、`粗 DEM` 有文件大小。

## 3. 启动

```powershell
python -m app.main
```

等价方式：双击项目根目录的 `启动器.bat`（它会自动找 Python 并传参给 `app.main`）。
`启动器.bat` 也支持命令行参数，例如 `启动器.bat --env`。

启动后你会看到：

- 顶部：标题 + `v4.0` 徽标 + **任务概要条**（任务类型 / 箭型 / 工位 / T0，常驻可见）；
- 第二行：工具条（新建 / 载入示例 / 保存任务 / ① 生成体检 / ② 开始计算（F5）/ 取消 /
  打开成果目录 / 环境自检 / 帮助（F1））；
- 左侧：**八步向导**（任务与箭型 → 轨道与时序 → 航警与落区 → 观测点 → 空间站与返回 →
  输出与模块 → 数据体检 → 运行与成果），每步右侧有状态徽标；
- 右侧：当前步骤页；底部有「← 上一步 / 下一步 → / 生成体检 / 开始计算（F5）」；
- 最底部状态栏：一行提示 + 右侧显示**工作区根目录**。

## 4. 用示例任务跑通全流程

「载入示例」内置一个长征二号丁 / 太原 LC-9 任务（含两条航警、一个山西晋中观测点、
500 km 级太阳同步轨道），用来证明安装与链路可用。

1. **载入示例**：工具条「载入示例」→ 概要条应显示「常规发射弹道 / 长征二号丁 / 太原 LC-9」。
2. **生成体检**：点「① 生成体检」。程序会补全缺失字段并跳到第 7 步，你会看到：
   - 体检明细表：字段 / 取值 / 来源 / 置信度 / 说明；
   - 下方左栏「低置信度项」、右栏「提示」；
   - 「反演计划」一行告诉你将优化几个参数、差分进化预算与预估耗时。
3. **开始计算**：点「② 开始计算（F5）」或直接按 `F5`。第 8 步会显示进度、实时日志、
   **步骤台账**（每步的 完成/跳过/不适用/未启用/失败 + 原因）与成果文件树。
4. **先看两个文件**（第 8 步工具条上有按钮，或用资源管理器打开）：
   - `report\任务摘要.md`：一页纸，含关键数字、关键节点、飞行阶段、输出完整性、提示；
   - `report\成果清单.md`：步骤台账 + 应产出项核对 + 全量文件清单。
5. 再按需看 `report\弹道仿真报告.md`（§0~§13）、`sky\`、`map\`、`viz\` 里的图。

成果默认落在 **`作品\`** 下（开发态即项目根的 `作品\`；可在菜单
「设置 → 工作区根目录…」改到别的盘）。目录名按「日期 + 箭型 + 工位」自动生成；
同名已有成果时会问「覆盖 / 新建副本 / 取消」。

## 5. 换成自己的任务：最小步骤

| 步 | 至少要做的 | 可以完全留空的部分 |
|---|---|---|
| ① 任务与箭型 | 选**任务类型**、选**火箭型号**、选**发射工位** | 遥号、载荷名/质量、任务名、T0 |
| ② 轨道与时序 | 一般什么都不用改（默认「自动推断」） | 参考轨道、制导参数、分离/抛罩时刻 |
| ③ 航警与落区 | 把 NOTAM 原文整段粘进来 → 点「解析原文」 | 无航警时改勾「预测落区」 |
| ④ 观测点 | 可留空（默认把发射场当观测点） | 全部 |
| ⑤ 空间站与返回 | 仅载人/返回任务需要 | 全部 |
| ⑥ 输出与模块 | 选「标准（推荐）」预设 | 其余 |
| ⑦ 数据体检 | 点「生成体检」，看低置信度项 | — |
| ⑧ 运行与成果 | `F5` | — |

三条硬性提醒：

- **任务类型选错会白算**：返回舱返回任务不需要发射场与上升段；载人任务才出空间站交会。
- **T0 可以留空**，但不能「既留空、又没有任何带 B)/C) 的航警」，否则程序报
  「无法确定起飞时刻 T0」。
- **箭型选「自定义/未知」也能跑**，但只会按通用中型液体模板给量级结果；要真值请用
  编辑器定义（见 [03_自定义箭型.md](03_自定义箭型.md)）。

## 6. 命令行等价做法（不打开界面）

```powershell
# 用内置示例跑一遍，成果写到指定目录
python -m app.main --cli --demo cz2d --workdir "作品\_试算"

# 只跑仿真数据 + 通用成果（最快，适合批量试算）
python -m app.main --cli --demo cz2d --modules export,summary --workdir "作品\_试算"

# 用自己保存的任务 JSON（界面里「保存任务 JSON…」得到的那份）
python -m app.main --cli --mission "作品\我的任务.json" --workdir "作品\我的任务"

# 已有成果的目录要复用，必须显式加 --overwrite（默认会自动新建 _2 副本）
python -m app.main --cli --mission "作品\我的任务.json" --workdir "作品\我的任务" --overwrite
```

命令行的数据体检、自动计划、步骤台账会直接打印在控制台；退出码 `0` 表示全部完成。

## 7. 首次运行常见问题

| 症状 | 原因 | 处理 |
|---|---|---|
| `python` 不是内部或外部命令 | 没装 Python 或没进 PATH | 装 Python 3.10+，勾选 Add to PATH；或用 `启动器.bat`（会自己找） |
| 启动报缺少 `numpy` / `scipy` | 依赖没装 | `python -m pip install -r requirements.txt` |
| 计算卡在「DEM 地形准备」很久 | 首次需要下载 SRTM 瓦片（每片解压后约 25 MB） | 耐心等首次；或**不勾选**「允许联网补全」，直接回退内嵌粗 DEM |
| 天空轨迹「首次出现时刻」偏差几十秒 | 用了内嵌粗 DEM（约 2 km 分辨率） | 联网补 1″ SRTM，或用菜单「设置 → 导入离线高程文件…」导入自制 GeoTIFF/HGT |
| 完全离线，跑得出结果吗 | 可以，运行期不需要网络 | 依赖需先在能联网的机器上装好；空间站/ DEM 走内置数据或本地瓦片 |
| 步骤台账里若干步显示「未启用」 | 「输出与模块」页没勾选对应模块 | 换「标准（推荐）」预设，或手动勾上 |
| 步骤台账里「跳过」 | 依赖不满足（如无观测点且关掉了「无观测点时用发射场」） | 看「说明」列的原因，回到对应步骤补数据 |
| CSV 用 Excel 打开是乱码 | 用了非 UTF-8 软件打开 | 本项目 CSV 统一写 UTF-8 BOM，Excel 直接双击即可；若仍乱码请用「数据 → 从文本」 |
| 文件夹路径含空格/中文 | 程序本身支持 | 但不要把工程放在 `C:\Program Files` 之类只读目录，成果要可写 |
| 界面字体模糊 | 高分屏缩放 | 程序已声明 DPI 感知；仍模糊可改用 100% 缩放或更新显卡驱动 |
