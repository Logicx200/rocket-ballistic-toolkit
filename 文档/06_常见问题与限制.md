### Q：数据体检老提示「参考轨道低置信度 / 未计侧向机动」怎么办？

v4.0.1 起这条提示的触发条件已经改了：**只要射向本身够准（σ_i≤2.5°），参考轨道就标"中"**，
说明里直接给 `i=xx.xx°±σ`，不再出现"未计侧向机动"这种笼统措辞。

如果仍然看到相关提示，按下面处理：

1. **只是"提示"不是"低置信度"**：若它与库内典型轨道差 >5°，提示会建议你显式指定轨道——
   到「② 轨道与时序」选一个内置模板/手填高度倾角，体检来源会变成「用户给定/高」，提示消失。
2. **真正标"低置信度"的参考轨道**只出现在：高度只能按箭型量级兜底、或射向几何病态
   （近赤道/近 180° 逆行，仅凭射向推不出倾角）。这两种情况都建议显式指定轨道。
3. **想彻底关掉自动推断**：步骤②把来源改为「内置轨道模板」；或在 CLI 传
   `--window-raan/--window-ltan` 之外，直接在任务 JSON 里写 `ref_orbit_mode=custom` + `ref_orbit`。
4. **模型局限**（3-DOF、末级平面修正按几何 dogleg、不计 Δv）属于报告 §9 的统一声明，
   不会逐任务重复标注。

## 1. 输入类

### 1.1 报「无法确定起飞时刻 T0」

- **原因**：T0 留空，且没有任何带 `B)/C)` 有效期的航警可供推断。
- **处理**：填一个 T0（`2026-11-19 06:50` 或 `2026-11-19T06:50:00Z`），或粘贴完整 NOTAM
  后重新「解析原文」。

### 1.2 报「无法确定发射场：请选择内置工位或直接给出经纬度」

- **原因**：工位没选、也没给坐标，且当前箭型库里没有该箭型的典型工位可回退。
- **处理**：选一个工位（或「场区（不指定工位）」），或选「自定义坐标」填经纬度。
- **补充**：若箭型库里有典型工位，程序会用它并给提示「未指定发射场，取该箭型典型工位（请核对）」。

### 1.3 报「疑似经纬度写反」

- **原因**：纬度 >90° 且经度 ≤90°。
- **处理**：本项目一律**纬度在前、经度在后**；改过来即可。坐标 (0,0) 也会被拒绝。

### 1.4 T0 输入框提示「无法解析」

- **处理**：用这四种写法之一：`2026-11-19 06:50`、`2026-11-19T06:50:00Z`、
  `2026-11-19 06:50 +08:00`、`2611182250`（NOTAM 压缩时间，按 UTC）。
  默认无时区标记时按**北京时间**解释。

### 1.5 发射时序某行提示「无法识别」

- **原因**：写了 `abc`、`0`、`-5`，或写了绝对时刻但 T0 无法解析。
- **处理**：用 `206 / T+206 / 206s / 2026-11-19T07:10:00Z` 之一，且必须 >0。

### Q：载人任务的发射 T0 是按下行对接窗口反推的吗？

v4.1 起可选：在「① 任务与箭型 → 起飞时刻」勾选**「载人任务：按交会窗口反推 T0」**。
勾选后运行时会先由空间站星历 + 发射场 + 上升段入轨点算**交会发射窗口**，再把 T0 平移到
可行窗口（或确认标称 T0 已在窗口内），并用该 T0 重跑弹道/落区/窗口/交会——
报告 §4.4 给出窗口清单与偏移量，§5.3 不会再出现"标称 T0 在窗口外、交会按窗口中心计算"
的两套 T0 说明。

不勾选时保留你填的 T0，只给"最近可行窗口 ±多少秒、ΔRAAN 多少度"的提示；若 T0 本身是航警推断值，
程序会**自动**按交会窗口反推（不需要勾选）。窗口完全由模型推算，不查询任何外部任务参数。

v4.3 起：**你在窗口内填的 T0 原样保留**（默认按 2° dogleg 预算加宽，约 ±8 min），
程序只按目标平面重飞并校核；窗口外才会平移。报告 §4.4 给出 dogleg 窗口、所需平面
修正与**入轨面残差**（实测入轨面 vs 空间站面）。交会与弹道严格用同一 T0。

## 2. 结果为空 / 步骤没跑

### 2.1 运行结束但某个图/文件没有

1. 打开 `report\成果清单.md` §2「输出完整性核对」，找 ✘ 缺失项；
2. 看 §1「步骤台账」里对应步骤的**状态与说明**；
3. 状态=「未启用（未勾选模块）」→ 步骤 ⑥ 把模块勾上重算；
   状态=「跳过」→ 按说明补数据（最常见：无观测点且关了「无观测点时用发射场」）；
   状态=「失败」→ 去 `运行日志.txt` 搜该步骤中文名。

### 2.2 天空轨迹/出现方位图没出

- 观察点为空，且**取消**了「无观测点时用发射场」；
- 或者 DEM 步骤失败但 sky 仍继续（会用粗 DEM，能出图但精度低）；
- 处理：加一个观测点，或重新勾上那个复选框。

### 2.3 全国地图没出

- 只有当 `map` 模块未勾选、或 `plot_map` 报错时才缺；
- 地图**不依赖观测点**，无观测点也会生成（只是不叠加观测点标注）。

### 2.4 `report\发射窗口计算.json` 没出

- 没有航警 **且** 没有任何平面约束（RAAN/LTAN/交会目标/SSO 倾角）时，`window` 模块会被自动关闭；
- 处理：给航警，或在步骤 ② 填 RAAN/LTAN。

### 2.5 返回任务里没有上升段文件

- 正常现象。返回任务的设计就是「不要发射场/火箭/上升段」，相关步骤在台账里统一记「不适用」
  并附原因（例如「返回任务不计算上升段弹道」）。

## 3. 落区与入轨

### 3.1 残骸落点不入航警区

按代价从低到高：

| 措施 | 说明 |
|---|---|
| 核对多边形顺序 | 航警多边形必须是 `[纬度, 经度]`；写反会导致「区在地球另一侧」 |
| 核对残骸类型 | `stage_hint` 与本级是否对应；程序运行时会用预测落点自动校正一次 |
| 提高反演预算 | 步骤 ⑥ 从「自动」改「精细」，或命令行 `--modules` 保留 invert 且手工加大 maxiter |
| 看残骸 cda | cda 直接决定落点远近，用 `sim\落点与射程.csv` 与区内距离反复微调 |
| 检查末级关机/分离 | 用箭型默认值先跑一遍，确认默认就能大致入区，再改时序 |

### 3.2 入轨根数异常（近地点塌陷/偏心率很大）

| 可能原因 | 怎么确认 | 处理 |
|---|---|---|
| 末级关机时刻被改坏 | 看体检与报告 §2.0「发射时序」 | 清空自定义时序，回到箭型默认 |
| 箭型推进剂/推力/比冲有误 | 编辑器第 ⑥ 页「性能预览」的理论 Δv 是否离谱 | 修正参数（见 [03](03_自定义箭型.md)） |
| 参考轨道与箭型不匹配 | 体检里参考轨道来源/置信度 | 换模板、手填或 TLE |
| 反演没收敛 | `sim\反演参数.json` 的 `converged` 字段 | 提高预算；程序会回退标称参数并提示 |

### 3.3 反演「没收敛」或耗时太久

- 反演是差分进化，预算越大越准、耗时近似线性；
- 「自动」按参数个数与置信度选预算；不想等就选「快速」或命令行 `--no-invert`；
- 反演不收敛时程序会**回退标称参数**并在日志/体检里说明，不会静默给出错误结果。

## 4. 空间站与返回

### 4.1 「空间站数据不可用 / 不覆盖任务时刻」

- 内置 OEM 快照只覆盖 **2026-11-20T00:00Z ~ 2026-11-27T00:00Z**；
- 处理：粘贴较新的两行 TLE，或「导入 TLE/OEM 文件…」，或勾「允许联网补全」后「在线拉取」；
- 数据优先级：用户 OEM > 用户 TLE > 内置 OEM > 内置 TLE（历元 ±45 天）> 在线 > 失败提示。

### 4.2 交会模块「不适用」

- 非载人任务不会算交会（`station`/`docking` 自动关闭）；
- 处理：把任务类型改为「载人发射弹道」，或选 CZ-2F 箭型。

### 4.3 返回任务跑不起来

- 返回段需要空间站星历：确认「启用空间站交会」是勾选状态；
- 只勾「启用返回舱返回」但未启用空间站时，会提示「返回段需要空间站星历」。

### 4.4 返回窗口为空

- 搜索区间由返回航警 `B)/C)` 决定（各 −3 h / +1 h）；无航警时按 T0±6 h；
- 若着陆场与轨道倾角几何上不可达（例如倾角 41.5° 的轨道想过境 42°N 附近但相位不对），
  窗口可能确实为空——先确认着陆场坐标与倾角是否矛盾。

## 5. 性能与环境

### 5.1 卡在「DEM 地形准备」很久

- 首次会从公开源下载 SRTM 1″ 瓦片（每片解压后约 25 MB，覆盖观测点/发射场周边）；
- 处理：等首次；或不勾「允许联网补全」（直接用内嵌粗 DEM）；或用「设置 → 导入离线高程文件…」。

### 5.2 用粗 DEM 时天空轨迹偏差

- 内嵌粗 DEM 约 2 km 分辨率，首次出现时刻误差可达数十秒；
- 报告与 `sky\天空轨迹_*.md` 会注明 DEM 模式；用于正式结论前请补 1″ SRTM 或导入自制高程。

### 5.3 运行慢

| 原因 | 加速办法 |
|---|---|
| 反演预算高 | 选「快速演示」/「快速」预算，或 `--no-invert` |
| 全量模块（天空+全国地图+三维+蒙特卡洛） | 换「标准（推荐）」；不改就只勾需要的 |
| 蒙特卡洛样本多 | 降到 100~300 |
| 全部并行进程 | 保持 0/1（差分进化串行更快） |
| 反复重算 | 用 `--modules export,summary` 只补数据 |

### 5.4 内存占用高

- 全国地图网格、DEM 瓦片缓存、蒙特卡洛样本都会占内存；
- 处理：一次只跑一个任务（别并行开多个窗口），降低地图精度/关掉 `map`，减少 `mc` 样本数。

### 5.5 中文乱码

| 场景 | 说明 |
|---|---|
| Excel 打开 CSV | 本项目 CSV 写 UTF-8 with BOM，Excel 双击应正常；若仍乱码，用「数据 → 从文本/CSV」并选 UTF-8 |
| 控制台输出 | 程序会把 stdout 重配为 UTF-8；老终端可先 `chcp 65001` |
| 日志/JSON | 一律 UTF-8；用支持 UTF-8 的编辑器打开 |
| 用 GBK 编辑器改过 config.json | 会出现解析失败；请用 UTF-8 保存（读入端已做 BOM 容错，但不认 GBK） |

### 5.6 路径含空格/中文

- 支持。项目本身就在中文路径下运行；
- 但不要把工程或成果目录放在 `C:\Program Files` 等需要管理员权限的位置；
- 极长路径（>240 字符）建议缩短工作区名。

### 5.7 没有 exe / 双击没反应

- 本版**未做应用程序打包**，仓库里没有 exe；
- 用 `python -m app.main` 或双击 `启动器.bat`（需 Python 3.10+）；
- 详见 [08_v4变更说明.md](08_v4变更说明.md)。

### 5.8 缺 `python-docx` 时没有 .docx

- 技术报告会只出 `.md`；`python -m pip install python-docx` 后重跑 report 步骤即可。

## 6. 交付自检（qc）FAIL 对照

`report\qc_report.json` 里每项有 `check` 与 `ok`；程序会把 FAIL 项翻译成建议
（`app/core/qc_summary.py`）。常见对照：

| FAIL 关键字 | 含义 | 建议 |
|---|---|---|
| 报告未撰写 | 技术报告缺失 | 检查 `report` 步骤是否启用/失败 |
| PNG | 图片缺失或宽度不足 | 确认天空/地图/KML 步骤跑完；天空主图要求宽度 ≥1600 px |
| KML | KMZ/KML 结构异常 | 检查 `viz\` 与 `engine\viz\files` 图标是否缺失 |
| 落区 | 落点未入区 | 提高反演预算、核对 `stage_hint` 与多边形顺序 `[lat,lon]` |
| 窗口 | 发射窗口为空 | 航警 B/C 未覆盖残骸到达时刻，或 T0 偏差过大 |
| 入轨 | 入轨根数异常 | 检查推进剂/推力/末级关机，或参考轨道是否与箭型匹配 |
| 天空 | 天空轨迹缺失 | 观测点是否存在、DEM 是否可用 |
| DEM | DEM 缺失 | 联网补 SRTM，或导入本地瓦片/自制高程 |
| NaN | 存在 NaN | 多为仿真发散：检查 dt 与箭型参数（尤其推力/质量/比冲的极端值） |

> 自检通过 ≠ 结论可用：自检只查「文件齐不齐、数值是否自相矛盾」。可信度仍看数据体检的
> 来源/置信度。

## 7. 已知限制

| 限制 | 具体含义 | 影响 |
|---|---|---|
| **3-DOF 质点弹道** | 只解质心三自由度运动，不含姿态、弹性、风场、六自由度耦合 | 事件时刻、落点、入轨根数是工程量级；不能用于控制律设计 |
| **交会是工程估算** | 相位调整 + Hohmann + 末段逼近的解析估算 | 给时间线与总 ΔV 量级，不是飞行程序，不是 GNC 方案 |
| **返回舱模型简化** | 弹道式再入 + 升阻比/倾侧角扫描 + 伞降分段 | 落点 1σ 是模型散布，不是真实制导精度 |
| **DEM 精度有限** | 在线为 SRTM 1″（约 30 m 网格），回退为内嵌粗 DEM（约 2 km） | 地形遮挡与首次出现时刻存在数十秒级误差 |
| **内置库置信度不一** | 28 型箭型来自公开资料整理，部分条目置信度「中/低」 | 报告与体检会标注；低置信条目的结果只作量级参考 |
| **不联网检索 NOTAM** | 程序不抓航警，只解析你粘贴的原文 | 航警的时效性与准确性由你负责 |
| **空间站星历覆盖有限** | 内置 OEM 仅覆盖 2026-11-20 ~ 11-27 | 超期需自备 TLE/OEM |
| **不提供飞行安全认证** | 落区、窗口、残骸散布都是分析结果 | 不得作为发射许可、安全评估或事故调查依据 |
| **未打包** | 只有源码运行方式 | 分发需要 Python 环境 |
| **单次一个任务** | 界面按单任务设计 | 批量请用命令行 + 脚本循环 |

## 8. 免责声明

> 仅供公开信息分析与教学使用，非实际发射/返回弹道，非官方信息。

- 本工具的输入来自公开资料与你粘贴的航警，输出是**模型计算结果**；
- 所有落区、窗口、可见性、交会/返回时序均不具备官方效力；
- 报告中标注为「自动推断 / 默认值」或置信度「低」的字段，引用时必须注明不确定性；
- 严禁用于飞行安全决策、空域协调、事故调查或任何需要官方背书场合。

程序也会把这段声明写进 `config.mission.disclaimer`、`report\任务摘要.md` 与
`report\弹道仿真报告.md` 的显要位置。
