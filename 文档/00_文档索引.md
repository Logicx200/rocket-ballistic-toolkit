# 00 文档索引

「火箭弹道工具箱 v4」把一次发射（或一次返回）任务变成一整套可交付成果：
3-DOF 上升段弹道 → 残骸落区 → 入轨根数 → 轨道平面/交会/返回窗口 → 天空可见性 →
全国地图 → 三维 KMZ → 不确定度 → 中文技术报告。**全程离线可跑**，任务类型分三类：
常规发射弹道 / 载人发射弹道 / 返回舱返回弹道。

本目录下的 markdown 是**唯一权威说明**；程序内 F1 帮助中心（`app/gui/help_text.py`，13 个主题）
是操作现场的速查版，两者互补、不重复抄写。

## 三条最快的路径

**只想验证「这软件能跑」**（不看细节）：

```powershell
cd "F:\DeepSeek工作区\火箭弹道工具箱_V4.0"
python -m app.main
# 窗口里：工具条「载入示例」→「① 生成体检」→「② 开始计算（F5）」
# 完成后先看 作品\<任务目录>\report\任务摘要.md
```

**只想跑一次仿真、不要图**（命令行，最快）：

```powershell
python -m app.main --cli --demo cz2d --modules export,summary --workdir "作品\_试算"
```

**遇到问题**：先看工作区的 `report\成果清单.md`（步骤台账 + 缺失项），再看
`运行日志.txt`；仍然不清楚就查 [06_常见问题与限制.md](06_常见问题与限制.md)。

## 术语速查

| 术语 | 含义 |
|---|---|
| T0 | 起飞时刻；程序内部一律 UTC，界面按北京时间显示 |
| 数据体检 | 逐字段列出「用了什么值、来源、置信度」的表，写在 `config.mission._provenance` |
| 来源 | 用户给定 / 内置库 / 自动推断 / 默认值 / 计算得出 |
| 反演 | 差分进化搜索制导参数，使落点入航警区、入轨接近参考轨道 |
| 参考轨道 | 入轨目标（高度/倾角/偏心率/RAAN/LTAN），对反演是软约束 |
| 航警 / 危险区 | NOTAM 描述的落区多边形；顶点顺序 `[纬度, 经度]` |
| 落区 | 残骸理论落点 + 对应危险区；判定看 `sim\落点与射程.csv` 的 `inside_zone` |
| 步骤台账 | 每步的完成/跳过/不适用/未启用/失败/取消 + 原因，写进成果清单与运行页 |
| 模块开关 | 「输出与模块」页的 15 个复选框；实际开关以 `config._v3.modules` 为准 |
| 预设 | 快速演示 / 标准（推荐）/ 全量 / 只要仿真 |
| 我的库 | 用户自定义数据（`user_data\`）：箭型、轨道、时序模板 |
| 软约束 | 不强行改弹道，只在反演评分里加分/减分 |
| 平面窗口 | 发射时能进入目标轨道面的时间段（由 RAAN/LTAN 决定） |

## 维护约定（改文档的人看）

- 界面文案、字段名、产物文件名一改，**本目录与 `app/gui/help_text.py` 要同步改**；
- 字段口径以代码为准：`app/core/model.py`（输入字段）、`app/core/config_build.py`（写入 config）、
  `app/core/summary.py`（应产出清单）、`app/core/runner.py`（步骤与状态）；
- 写文档前先 grep 验证，不要凭印象（本目录 v4 版就是这么写的）。
