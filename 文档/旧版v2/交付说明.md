# 火箭弹道工具箱 v2.0 —— 交付说明

> 本文件夹是 `rocket_ballistic_toolkit_v1.0.zip` 的分析结论 + 改进版本（v2.0）。
> 物理方程与数据契约不变；改进集中在**数值离散化、并行、算法与工程可运行性**。
>
> 仅供公开信息分析与教学使用，非实际发射弹道。

## 二、核心结论（同机、同算例实测）

| 指标 | v1.0 | v2.0 | 变化 |
|---|---|---|---|
| 单次上升段仿真（含残骸） | 0.954 s | **0.090 s**（accurate, dt=0.5） | **10.6×** |
| 同上，默认配置（accurate, dt=0.2） | — | 0.189 s | 5.0× |
| 蒙特卡洛 N=250 | 187.5 s | **10.8 s**（8 进程） | **17.4×** |
| 全国最大高度角地图 | 16.9 s | **9.5 s**（CSV 逐位不变） | 1.8× |
| 出现方位地形判读图 | 21.8 s | **4.0 s** | 5.4× |
| 仿真 + 数据导出 | 1.84 s | **0.56 s** | 3.3× |
| 全流水线（无 MC / 含 MC 250） | 47.9 / 235.4 s | **21.1 / 31.9 s** | 2.3× / **7.4×** |
| 入轨半长轴对 dt 的敏感性 | 18.55 km（0.02→收敛） | **0.63 m**（0.5…0.02） | 4 个数量级 |
| 与 v1 结果一致性 | — | legacy 口径逐位等价（轨迹 0.008 m） | — |

关键点：v1 默认 `dt=0.02` 存在 **+18.55 km 半长轴、+8.4 m/s 入轨速度**的系统性偏差
（事件时刻被量化到步边界、质量步首一阶扣减）；v2 把事件对齐到精确时刻、质量纳入 RK4，
因此在**更快**的同时**更准**。详见 `docs/优化分析报告_v2.md` §3。

## 三、怎么运行

```powershell
# 在本文件夹下打开 PowerShell
$env:PYTHONIOENCODING="utf-8"; $env:MPLBACKEND="Agg"

# 一键（DEM 已就绪时；没有 DEM 会自动退化并提示，见 §五）
powershell -NoProfile -ExecutionPolicy Bypass -File .\run_all.ps1 -SkipDem -MC 250 -Jobs 8

# 换新任务时（跳过带本任务定制常量的 6b 图）
powershell -NoProfile -ExecutionPolicy Bypass -File .\run_all.ps1 -SkipDem -SkipAppear

# 复现 v1.0 口径的数字（逐位一致）
powershell -NoProfile -ExecutionPolicy Bypass -File .\run_all.ps1 -SkipDem -Legacy

# 只要最小子集
python scripts\export.py --config config.json
python scripts\plot_sky_refstyle.py --config config.json
python scripts\make_kml_refstyle.py --config config.json
```

首次使用真实地形：

```powershell
python scripts\fetch_dem.py --config config.json      # 下载 SRTM 1″ 瓦片（见 §五 网络说明）
```

## 四、数值口径（先用这一段，避免误解）

`config.json` 的 `numerics` 段：

| 口径 | 事件时刻 | 质量/推进剂 | 用途 |
|---|---|---|---|
| `accurate`（默认） | 精确落在事件时刻 | 随 RK4 四阶积分 | 新任务；dt 可 0.2–0.5 s |
| `legacy` | 量化到 dt 步边界 | 步首一阶扣减 | **逐位复现 v1.0 已交付数字** |

两者物理方程完全相同，差别只在离散化。命令行：`--legacy / --accurate / --dt`；
`run_all.ps1` 用 `-Legacy / -Accurate`。

**注意**：若采用 `accurate` 作为正式交付口径，需要
① 用 `invert.py --jobs 8` 重新率定制导参数（v1 参数是在 v1 的离散化误差下调出来的）；
② 用真实 SRTM 重跑天空轨迹；③ 重跑 `mc.py` 更新 DRMS。

## 五、关于 DEM（重要）

- 本文件夹**不含 SRTM 瓦片**（43 个瓦片解压后约 1.1 GB），也不含任何合成/占位地形；
- `示例运行/sky/` 是在**无 DEM** 条件下生成的：脚本打印警告并退化为平地遮挡角 −0.1°，
  其 MD 里也有说明；**正式结论必须用真实 SRTM 重跑**；
- `示例运行/map/`（全国最大高度角地图）不使用 DEM，是真实的几何计算结果；
- 实测本机到 AWS S3 的下载速度仅 ~11 KB/s（对照 Cloudflare ~190 KB/s、naciscdn ~108 KB/s），
  43 个瓦片约需 12 小时。可换网络/代理后重跑 `fetch_dem.py`（瓦片级幂等，已下好的会跳过），
  或在别的机器下完 `data/dem/hgt/` 后整目录拷入。

## 七、验证与复现

```powershell
# 精度+性能基准（一条命令出表）
python scripts\bench.py all --config config.json --reference <v1工程>\sim --runs 3

# 与 v1 参考工程逐位回归（默认 legacy 口径）
python scripts\regression_check.py --config templates\config_cz2d.json --reference <v1工程>\sim

# 交付自检（25 项）
python scripts\qc.py --config config.json
```

本版本实测结果：

- legacy vs v1：轨迹最大 0.008 m，落点 0.002 km，a/e/i 差 0.000，事件时刻完全相同；
- accurate：dt=0.5…0.02 的入轨半长轴极差 0.63 m，事件时刻逐位相同；
- QC：25/26 PASS（唯一 FAIL 是“报告未撰写”，属预期的人工环节）。

## 八、已知限制

1. 天空轨迹/遮挡角依赖真实 SRTM；本机网络受限，示例未含真实地形。
2. `data/ne/` 已随包提供（Natural Earth public domain）；如需重建：`python _tools\fetch_ne.py`（需 `pyshp`）。
3. `pandas` 可选（`plot_sky.py` 自检会自动回退 csv）。
4. Windows PowerShell 5.1 执行策略受限时，用 `powershell -NoProfile -ExecutionPolicy Bypass -File .\run_all.ps1`；
   `run_all.ps1` 已带 UTF-8 BOM，避免中文乱码。
5. 残骸气动仍为常值 CdA（与 v1 一致，未做物理升级；升级会改变落点，需要重新标定）。
6. **三个脚本带本任务定制常量**（换任务时按 `prompts/09_换任务SOP_已知航警.md` §8 处理）：
   `make_kml_refstyle.py`（T0/发射场/阶段标题/两个航警区多边形）、
   `make_appearance_terrain_map.py`（首次/最大/消失方位与出现扇区）、
   `plot_map.py`（中国 72–136°E/15–55°N 网格与国界）。
   其余模块完全配置驱动。
