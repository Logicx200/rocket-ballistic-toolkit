## 2. `guidance`

```jsonc
"guidance": {
  "mode": "shooting_plane",   // shooting_plane（方位角恒定，射面导引，推荐）/ inertial_plane
  "azimuth_deg": 188.0,       // 发射方位角（反演未知量）
  "t_v": 7.76, "t_p": 169.08, "pitch_power": 1.056,   // 垂直段/幂律转弯段/指数（反演未知量）
  "t_fairing": 206.0,         // 抛罩 MET（反演未知量）
  "fairing_divert_mps": 4.0,  // 两半罩横向分离速度
  "plane_keeping": false, "yaw_tau": 150.0,
  "i_target_deg": null,       // 末级 dogleg 目标倾角（null=不修正）
  "dt": 0.02, "debris_dt": 0.25, "post_seco_s": 60.0
}
```

## 3. 反演未知量怎么选

- **方位角**：由目标落区/走廊几何决定，首选未知量；
- **俯仰程序**（t_v/t_p/k/各级 pitch_end_deg）：决定落点射程与入轨高度；
- **抛罩时刻**：整流罩落点决定（本例 T+206 s）；
- **末级关机 MET**（`seco_met`）：由目标轨道高度决定（本例 723.78 s）；
- 助推器型：再加 **助推器 jettison_met** 与 **一级 pitch_end**。
- 反演目标见 `config.inversion`；DE 预算 `maxiter/popsize`（精细解 20×10 约 10–20 min）。

## 4. 倾角冲突处理流程（必读）

1. 由航警几何反演得到“航警约束主解”倾角（本例 94.7°）；
2. 查公开参考轨道（SSO 任务常为 97.4–97.5°）；
3. 两者差 >0.5° 时：**两个方案都出**，并计算轨道面修正代价
   Δv ≈ 2·v·sin(Δi/2)（本例 2.72° → ≈360 m/s）；
4. 报告写清“主解采用航警约束，对照情景采用公开轨道”，KML/图件只用主解（避免混用）。

## 5. 换箭型后的必做验证

```powershell
python scripts/regression_check.py --reference <旧案例 sim 目录>   # 通用模型回归
python scripts/export.py --config config.json                       # 事件/落点是否合理
```
若事件时刻与公开时序差距 >2 s，先查推力/比冲/推进剂与抛罩时刻。
