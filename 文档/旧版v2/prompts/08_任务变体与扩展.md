# 任务变体与扩展

| 变体 | 改动点 |
|---|---|
| **无航警（自由设计）** | `notams` 置空；用 `mission.reference_orbit` 作唯一目标；`invert.py` 目标函数退化为轨道匹配；报告写“落点无约束、仅给理论射程”。 |
| **多落区/多残骸** | `notams` 多条 + `stage_hint` 指向对应级/整流罩；`debris` 每对象给 `cda/extra_mass`；`export.py` 自动按对象输出落点行。 |
| **带助推器** | 填 `vehicle.boosters`（count/thrusters/jettison_met）；`dynamics.py` 自动在耗尽/程序时刻分离并生成 `booster_N` 残骸；事件表出现“助推器分离”。 |
| **3 级/更多级** | `stages` 追加；`pitch_end_deg` 每级一个；末级给 `seco_met`；`export.py` 的命名规范化自动把“一级关机/分离”映射为规范名（2 级时）。 |
| **夜间/跨晨昏线发射** | `plot_map.py` 的晨昏线已含 0/−6/−12/−18°；天空轨迹增加“火箭受照/地影”判定（`sky_summary.json.solar`）；报告注明观测者晨昏状态。 |
| **海上/赤道发射** | `launch_site` 填海上平台坐标；DEM 缺瓦片按 0（海平面）处理；落区判定的多边形改海上矩形；`plot_map.py` 陆域掩膜只用于显示。 |
| **无指定观测点** | 跳过 `plot_sky*.py` 与 `make_appearance_terrain_map.py`；或自选观测点加入 `observers`。 |
| **多观测点** | `observers` 多条；`plot_sky.py --obs <id>` 各出一份；`plot_map.py` 可标多点。 |
| **需要反演多解分析** | 多组初值/多组约束分别跑 `invert.py`，在报告给“等效参数族”（如方位角与抛罩时刻的耦合）。 |
| **需要精度评估** | `mc.py` 增大 N；再加 `oat.json`（单因子 ±1σ/±3σ 扫描）；对落点余量做最坏情况分析。 |
| **需要正式报告/幻灯片** | 报告模板见本项目 `report/弹道仿真报告.md` 结构；幻灯可用 office 技能从报告要点生成。 |
| **参考样式复刻** | 把参考图/参考 KMZ 放 `references/`（只读）；按 `03_绘图风格规范.md` 对齐配色/线宽/图层/标注；不要改动原工程。 |

## 扩展新功能时的约定

1. 新数据先加到 `export.py` 的数据契约（并更新 `05_数据契约.md` 与 `qc.py`），下游脚本只读契约。
2. 新图件遵循 `03_绘图风格规范.md`：中文标题、色条、图例、免责声明、PNG ≥1600 px。
3. 新脚本的 ROOT 解析统一用：
   `ROOT = os.environ.get("RK_ROOT") or os.path.dirname(os.path.dirname(os.path.abspath(__file__)))`
4. 新脚本必须能在“空工作区 + 只有 config.json”情况下给出可读报错（提示先跑 export/fetch_dem）。
