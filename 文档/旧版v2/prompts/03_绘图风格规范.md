# 绘图风格规范

> 本规范来自一次真实交付（CZ-2D 遥106）：**天空轨迹**与**三维 KMZ** 的样式由用户指定，
> 其余图件为本工具箱默认风格。换任务时只改“最小改动清单”里的项。

## 1. 天空轨迹（参考样式主图 `天空轨迹_<obs>.png`）

| 元素 | 规范 |
|---|---|
| 画幅 | 单幅方位角-高度角（不做子图）；1870×1234 px 左右；`dpi=150` |
| X 轴 | 方位角 (°)，正北=0、顺时针；范围覆盖轨迹 ±6°（跨 0° 时用 360 偏移而非换轴） |
| Y 轴 | 高度角 (°)；下限含地平线下残骸落点方向（约 −5°），上限比峰值高 8° |
| 轨迹 | 按 MET 着色，`viridis`；线宽 2.8；右侧竖色条标注「时间 t (s)」 |
| 地形遮挡 | 棕色实线（线宽 2.6）+ 米色半透明填充到底部；图例「地形+地球曲率遮挡区」 |
| 事件 | 黑点 + 就地标注「名称 / T+xxx s」；与最大高度角同点的事件合并进同一注释框 |
| 三要素 | 绿星=首次出现、橙圈=最大高度角、品红方块=消失，各带数值标注与引线 |
| 残骸 | × 标记（地平线下）；文字说明放底部信息框 |
| 图例/信息框 | 左上图例（带数值）、底部居中白底圆角信息框（可见时长/受照比例/不确定度/残骸方向） |
| 标题 | 两行：①「天空轨迹（方位角-高度角）：<地点>（lat, lon，高程≈X m）看 <箭型> 上升段」②「颜色=时间（黄→深紫为早→晚）；棕线以下=地形+地球曲率遮挡区；T0=…；观测点太阳高度…°」 |
| 字体 | `common/plotstyle.setup()`（msyh.ttc）；标题 13.5、轴标签 11、注释 8–8.6 |

## 2. 出现方位地形判读图（`出现方位地形示意图_<obs>.png`）

四面板：**(a)** 观测点周边 30 km 地形晕渲+等高线+方位射线+遮挡地形标注；**(b)** 0–360° 天空线；
**(c)** 出现扇区放大（含规范口径细虚线作对照，并标注近场伪影）；**(d)** 出现方位地形仰角剖面。
主曲线一律「稳健天空线」（人眼高 1.6 m、忽略最近 200 m、300 m 中值去噪）。

## 3. 全国最大高度角地图

- 单幅中国区域（默认 72–136°E × 15–55°N，0.2°），等值填色 + 城市标注 + 观测点标注；
- 叠加 T0 晨昏线（0°/−6°/−12°/−18° 等值线）与夜间半透明阴影、星下点轨迹；
- 单独出「晨昏线与阳光可见性」图（窗口起止两条晨昏线）；
- 中文标题、色条标注「最大高度角 (°)」、右下角统计框（最大/最小/中位数/格点数）。

## 4. 三维 KMZ/KML（`弹道三维_含残骸坠落.kmz`）

参考样式（用户指定）：
1. **Document 级**：标题 + 长描述（任务/工位/T0/采样/阶段配色/落区/落点/入轨/说明）+ Document `<LookAt>`（tilt 30、range 1.5e6）；
2. **Folder 弹道（三维+星下点）**：起飞点 + 各飞行阶段彩线（width 6，红 ff4646ff / 橙 ff00a5ff / 黄 ff28f0ff / 绿 ff82ff46）+ 星下点洋红线（ffff28ff，width 3，clampToGround）；
3. **Folder 飞行事件（N）**：`icon_key`/`icon_event` 图标点，说明含「T+…（UTC / 北京时）/高度/速度/质量/备注」；
4. **Folder 落区与残骸落点**：危险区半透明多边形（LineStyle width 5、PolyStyle alpha 0x46）+ 中心标注 + Q 行圆（青 e6ffeb00）+ 落点 `icon_impact_in/out`；
5. **Folder 时间动画（gx:Track，N 点）**：1 s/点；
6. **Folder 预设视角与 Tour**：3 个 LookAt + `gx:Tour`（FlyTo duration 2.4、`gx:flyToMode=smooth`、tilt 50）；
7. **Folder 残骸坠落曲线**：每种残骸一个子文件夹（分离点 + 3D 曲线 width 5 + 地面投影 width 2 + 1 s Track，默认 `<visibility>0</visibility>`）。

KML 技术要求：颜色顺序 **aabbggrr**；`kmz` 自包含（`doc.kml` + `files/icon_*.png`）；
gx:Track 的 `when`/`gx:coord` 数量相等且时间严格递增；`<description>` 用 CDATA；图标用相对路径 `files/`。

## 5. 配色/字体/尺寸默认值

- 主色：#1f77b4（主）、#ff7f0e（次）、#2ca02c（成功/区内）、#d62728（告警/失败）、#8B4513（地形）、#D2B48C（遮挡区）。
- 中文字体：`plotstyle.setup()`；数学/单位用 ASCII，避免字体缺字。
- PNG：宽度 ≥1600 px；白底；`bbox_inches="tight"`；文件用中文名。

## 6. 新任务“最小改动清单”

1. `config.json` 的 `mission`（任务名/箭型/T0/工位/参考轨道）与 `notams`/`observers`；
2. 各脚本顶部常量：阶段配色（若级数变化）、任务文案（Document 标题、图标题）、图标文件名；
3. 观测点 id（`--obs`）；
4. 报告中的关键数字表（由 `sim/*` 自动读取，勿手抄）。
