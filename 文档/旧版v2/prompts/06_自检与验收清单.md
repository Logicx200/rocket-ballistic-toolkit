# 自检与验收清单（DoD）

## 一键自检

```powershell
python scripts/qc.py --config config.json       # → report/qc_report.json，全 PASS 才交付
python scripts/regression_check.py --reference <参考 sim 目录>   # 换箭型后建议跑一次
python scripts/bench.py all --config config.json --reference <参考 sim 目录>  # v2：性能+精度
```

> **v2.0 追加验收项**：
> 1. `run_all.ps1` 结束时打印「分步耗时表」，总耗时应与 `docs/精度与性能验证_v2.md` §6 同量级；
> 2. 交付若用 `accurate` 口径，必须附 `scripts/bench.py accuracy` 的 dt 收敛表（极差 < 1 m）；
> 3. 交付若要与旧版数字对齐，用 `--legacy` 跑一次并确认 `regression_check.py` 全 PASS；
> 4. 天空轨迹的 DEM 必须用真实 SRTM（`data/dem/hgt/` 非空且为 25 934 402 B/瓦片），
>    不得使用任何合成/占位瓦片。

## A. 文件与格式

- [ ] `sim/` 9 个文件齐全（见 `05_数据契约.md`），行数合理、无 NaN、列名一致。
- [ ] `sky/`：主图 + 详细版 PNG（宽度 ≥1600 px）、CSV（≥8 列）、MD、`sky_summary.json`、出现方位地形判读图 + 数据 JSON。
- [ ] `map/`：全国地图 PNG、晨昏线图、`网格.csv`（行=行数×列数）、`统计.json`。
- [ ] `viz/`：KMZ（自包含）+ KML + `校验_KML.json` + GE 截图 2 张 + `GE实测验证.md`。
- [ ] `uncertainty/`：`mc_samples.csv`（N≥200）、`mc_stats.json`（1σ/DRMS/95%/入区率）。
- [ ] `report/`：`弹道仿真报告.md`（≥12 章、内嵌全部图件）、`发射窗口计算.json`、`qc_report.json`、`交付物清单.md`。
- [ ] `sources/`：`来源清单.md`（每条 URL+访问日期）与原始存档。

## B. 数值一致性

- [ ] 事件时刻/落点/入轨根数在 报告 = `sim/*.csv` = KML 说明 中一致（建议脚本生成表）。
- [ ] 落点全部在对应航警区内，给出距边界距离；若在区外必须解释（模型口径/栅格舵受控落区等）。
- [ ] 入轨根数与公开参考轨道对比，差异原因写明（如倾角冲突/载荷未确认）。
- [ ] 观测点坐标与配置/报告/`sky_summary.json` 三处一致（`qc.py` 会查）。
- [ ] 首次出现/最大高度角/消失三要素与 `sky_summary.json` 一致。

## C. 图件与视觉

- [ ] 天空轨迹主图符合 `03_绘图风格规范.md`（时间色条/遮挡线/事件标注/三要素/信息框/两行标题）。
- [ ] 出现方位判读图用稳健天空线，无“方波”平台（规范口径仅作细虚线对照并注明）。
- [ ] KMZ：阶段彩线、事件图标、危险区+Q 行圆、落点、gx:Track 动画、LookAt+Tour、残骸坠落曲线齐全。
- [ ] GE 实测：打开后时间滑块覆盖 T0→最终落点；截图非空白且图层可见。

## D. 报告与合规

- [ ] ≥12 章：任务与来源/箭型/模型/反演/验证/天空轨迹/全国地图/三维/不确定度/窗口/精度与局限/清单/来源。
- [ ] 含**假设、多解性、精度与局限、免责声明**；所有数值可追溯到脚本或公开来源（URL+日期）。
- [ ] 未修改其他任务工程目录；交付物中文命名；无第三方版权素材。

## E. 常见返工信号

| 现象 | 先查 |
|---|---|
| 落点在区外 | 方位角/俯仰程序/抛罩时刻；航警多边形顺序 |
| 天空轨迹遮挡线是方波 | 是否用了规范口径（改用稳健天空线） |
| 出现时刻差 10 s 以上 | 观测点坐标/高程、DEM 是否覆盖 |
| KMZ 线条变白 | 是否在 GE 里另存 |
| 全国地图与天空轨迹不一致 | 观测点 id / 网格分辨率 / 同一 `sim/` 数据 |
| MC 入区率异常低 | 落点设计余量、随机源 σ 是否过大 |
